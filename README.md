# Christ Emmane — Portfolio

Portfolio public de Christ Emmane Goma.

## Publication

Le site est publié automatiquement par GitHub Actions à chaque modification de la branche `main`.

Dans **Settings → Pages**, sélectionner **GitHub Actions** comme source de publication.

## Fonctions

- présentation et coordonnées ;
- projets détaillés ;
- parcours détaillé ;
- assistant Keth pour les réponses de base ;
- mise en page adaptée aux téléphones et aux ordinateurs.

L’espace privé et la conservation des messages seront ajoutés dans une prochaine étape avec un service sécurisé séparé.
